# Securitybeleid

Meld beveiligingsproblemen niet in een openbaar issue. Gebruik GitHub **Security → Report a vulnerability** in deze repository.

Vermeld waar mogelijk de Hass-Cleaner-versie, Home Assistant-versie, relevante logregels zonder tokens of geheimen en een reproduceerbaar scenario. Deel geen volledige auditrapporten als daarin persoonlijke entitynamen of paden staan.

Alleen de nieuwste release krijgt beveiligingsupdates. Hass-Cleaner verwijdert in de experimentele reeks geen bestanden, entities of apparaten. De afzonderlijke Recorder-purge gebruikt de officiële Home Assistant-actie en vereist een expliciete bevestiging.
